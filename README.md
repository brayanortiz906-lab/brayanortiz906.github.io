# Brayan Ortiz Calle — Portafolio Profesional V2

Portafolio web multi-páginas con temática aventurera / gaming / vehicles.

🔗 **Sitio:** [https://brayanortiz906-lab.github.io/BrayanOrtizCalle/](https://brayanortiz906-lab.github.io/brayanortiz906.github.io/)

## Estructura

```
/
├── index.html          # Inicio (Hero + proyectos destacados)
├── sobre-mi.html       # Biografía, valores, pasiones
├── experiencia.html    # Timeline de experiencia laboral
├── proyectos.html      # Proyectos con filtros por categoría
├── habilidades.html    # Skills: Adobe, lenguajes, herramientas
├── galeria.html        # Galería visual
├── contacto.html       # Contacto + formulario
├── css/
│   └── style.css       # Todos los estilos
├── js/
│   ├── main.js         # Navegación, animaciones, partículas
│   └── filters.js      # Filtro de proyectos (solo proyectos.html)
└── img/
    └── perfil.jpg      # Tu foto de perfil (260×340px recomendado)
```

## Páginas

| Página | Contenido |
|--------|-----------|
|Inicio|Hero animado con partículas, stats, proyectos destacados|
|Sobre Mí|Biografía, valores, hobbies (videojuegos, vehículos, aventura)|
|Experiencia|Timeline profesional con Dan Carlton + Multimpresos|
|Proyectos|6 proyectos con filtros (Gráfico/Digital/Impresión)|
|Habilidades|Skill bars de Adobe, lenguajes (Java, Python, JS, etc.)|
|Galería|Grid visual de trabajos|
|Contacto|Formulario mailto + datos de contacto|

## Personalizar

1. **Foto:** Reemplazar `img/perfil.jpg` con tu foto real
2. **Proyectos reales:** Reemplazar iconos emoji con `<img>` reales
3. **Formulario:** El formulario usa `mailto:` — para backend real, usar Formspree o similar

## Temas visuales

- **Colores:** azul bloqueador (`#38bdf8`), violeta (`#7c3aed`), dorado (`#f59e0b`)
- **Fondo:** deep navy `#060a0f`
- **Animaciones:** partículas conectadas, fade-in al scroll, skill bars, counters, floating badges, glowing borders
- **Temática:** gaming HUD, aventura, vehículos
- **Responsive:** mobile-first, menú hamburger
